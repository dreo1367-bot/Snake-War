# P2P Чат (C# / .NET 8)

Настоящий P2P-чат **без серверов и без лишних кнопок**:
запустил EXE на двух компьютерах в одной Wi-Fi/LAN сети — они **сами находят друг друга** (авто-сканирование IP) и соединяются. Пишешь — летит.

## Как это работает
1. При старте приложение поднимает **TCP-сервер чата** на порту `51111`.
2. Каждые 3 секунды рассылает **UDP-broadcast «DISCOVER»** на broadcast-адреса всех сетевых карт (port `51112`) — так находятся все, кто запустил программу в этой же подсети.
3. Найдя соседа, **автоматически подключается** к его TCP-порту (никаких «введите IP» — можно и вручную, но не нужно).
4. Сообщения летят по протоколу: `HELLO <ник>` → `MSG <ник>:<текст>` (UTF-8, кириллица ок).

## Управление
- Запустил → ввёл ник → всё, дальше само.
- Enter или кнопка ➤ — отправить сообщение всем соседям.
- Справа — список онлайн-соседей, сверху — счётчик.

## Сборка в EXE (Windows x64, standalone)
```bash
dotnet publish P2PChat -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
Готовый `P2PChat.exe` (~150 МБ, ничего ставить не надо) собирается автоматически GitHub Actions и выкладывается во вкладку **Releases**.

## Тесты
Автотест сетевой логики (два экземпляра обмениваются сообщениями по localhost): `tests/NetTestLib` — `dotnet run -c Release` → **TEST PASSED**.

## Файлы
- `P2PChat/Network.cs` — вся сеть: TCP-чат + UDP-discovery + автоподключение
- `P2PChat/MainForm.cs` — тёмный минималистичный интерфейс (чат + список соседей)
- `P2PChat/Program.cs` — точка входа
- `.github/workflows/build.yml` — автосборка EXE и релизы

⚠️ При первом запуске Windows Firewall спросит разрешение для портов 51111/51112 — жми «Разрешить» (без этого соседи тебя не увидят).
