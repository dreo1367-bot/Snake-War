# 🏀 Весёлый Мяч 2D (C# / WinForms)

Простая и смешная 2D-игра: **бери мышкой мяч и прикольно бросай его!**
Мячи прыгают, отскакивают от стен и пола, крутятся, сталкиваются друг с другом,
летят искры, звучат пики и меняются смайлики настроения 🙂😄😵.

## Управление
| Клавиша / мышь            | Действие                                   |
|---------------------------|--------------------------------------------|
| ЛКМ зажать на мяче      | Взять мяч                                  |
| Отпустить после размаха   | Бросить! Чем быстрее — тем мощнее 💥       |
| Двойной клик по пустому   | Появляется новый мяч                       |
| `Пробел`                  | Новый случайный мяч                        |
| `R`                       | Сброс мира                                 |
| `M`                       | Включить/выключить звук                    |

Сверху показывается статистика: броски, отскоки, количество мячей.

## Как запустить EXE (Windows)
1. Скачай `BallGame.exe` из **Releases** этого репозитория (или из Artifacts GitHub Actions).
2. Просто дважды кликни — ничего устанавливать не нужно (self-contained сборка).

## Сборка из исходников
Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0):

```bash
dotnet publish BallGame/BallGame.csproj -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish-out
```

Готовый файл появится в `publish-out/BallGame.exe`.

## GitHub Actions
Файл `.github/workflows/build.yml` автоматически собирает EXE на Windows-раннере
при каждом пуше в `main`/`master`, выкладывает его в **Artifacts** и создаёт **Release**.

## Структура проекта
```
BallGame/
  BallGame.csproj   – проект net8.0-windows (WinForms)
  Program.cs        – точка входа
  MainForm.cs       – окно игры, ввод мыши, игровой цикл, физика столкновений, HUD
  Ball.cs           – мяч: гравитация, отскоки, трение, вращение, смайлики
  Particles.cs      – искры при ударах и бросках
  Sound.cs          – звуки через Console.Beep в фоновом потоке
```
